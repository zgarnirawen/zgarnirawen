### `Multilingual-AI-Productivity-Assistant`

Full-stack AI productivity assistant developed during my **AI Summer Internship at 3LM Solutions**.

```text
Frontend  : React Native / Expo / TypeScript
Backend   : Node.js / Express / TypeScript
AI        : Groq / LLaMA 3.3 70B
Database  : Prisma / SQLite
Voice     : Speech-to-Text / Text-to-Speech
Testing   : Regression / E2E / Validation
CI        : GitHub Actions
```

The system converts natural-language requests into structured productivity actions using:

```text
User Input
    ↓
Intent Detection
    ↓
Entity Extraction
    ↓
Validation
    ↓
Action Proposal
    ↓
User Confirmation
    ↓
Action Execution
```

The project focuses on reliable AI integration rather than treating the LLM as an uncontrolled execution layer.

Repository:
